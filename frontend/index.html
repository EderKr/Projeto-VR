Instruções

Como jogar

Antes de começar

Calibre a cabeça antes da partida. A calibração define sua posição neutra e ajuda o jogo a entender agachar, pular, desviar e atacar corretamente.

Durante a luta

Observe o ataque do inimigo. Incline o corpo para os lados para desviar, agache quando o golpe vier alto e pule quando o ataque vier baixo. Para atacar, dê uma cabeçada quando o inimigo ficar vulnerável.

Teclado

← desviar para a esquerda → desviar para a direita ↓ agachar Espaço pular ↑ atacar

Modo personalizado

No jogo, abra o menu de personalizar partida para escolher o inimigo, ajustar vidas, definir quantos ataques são necessários para vencer e ativar valores infinitos quando quiser treinar sem limite.

Histórico

Ao jogar conectado, suas partidas são salvas no histórico. Ele mostra ações, acertos, erros, precisão e reação média para acompanhar sua evolução.
